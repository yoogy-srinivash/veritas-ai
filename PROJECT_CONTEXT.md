# Veritas AI — Project Context & Engineering Standards

## 1. Project Overview
**Veritas AI** is a multimodal NLP-based content verification system designed for academic and research evaluation.
The system ingests paired text-image claims and classifies digital content as **REAL**, **FAKE**, or **UNCERTAIN**.

- **Dataset**: Fakeddit benchmark, targeting 5,000 paired multimodal samples (balanced 50% REAL, 50% FAKE) subject to image link decay.
- **Text Encoder**: DistilBERT (`distilbert-base-uncased`).
- **Image Encoder**: ResNet50 (`torchvision.models.resnet50`).
- **Fusion Strategies**:
  1. *Feature-Level Fusion*: Intermediate projected concatenation ($\mathbb{R}^{256} + \mathbb{R}^{256} \to \mathbb{R}^{512}$) + MLP classifier.
  2. *Decision-Level Fusion*: Out-of-fold (OOF) trained meta-classifier over unimodal logits to prevent data leakage.
- **Explainability**:
  - Text: SHAP `shap.Explainer(..., masker=shap.maskers.Text(tokenizer), algorithm="partition")` with `max_evals=100`, served asynchronously with SHA-256 caching.
  - Image: Grad-CAM on ResNet50 `layer4[-1]`, capturing gradient activation saliency (not physical manipulation forensics).
  - Modality Attribution: Modality Sensitivity ($\Delta P$ prediction drop upon masking text vs image).
- **Uncertainty & Selective Classification**:
  - Training is binary (`REAL` vs `FAKE`).
  - Validation temperature scaling strictly minimizes Negative Log-Likelihood (NLL).
  - Rejection threshold $\tau^*$ is empirically swept on the validation set targeting $\ge 90\%$ selective accuracy (or optimal selective F1) while reporting coverage.
  - Final evaluation conducted on the untouched 750-sample test set.
- **Tech Stack**:
  - Frontend: React 18 / Vite / TypeScript / Tailwind CSS (Clean light academic journal aesthetic).
  - Backend: Python 3.12 / FastAPI / SQLAlchemy / SQLite.
  - Training: Google Colab (GPU-accelerated).
  - Inference: Local machine (CPU-optimized PyTorch).

## 2. Strict Engineering Constraints

1. **No Data Leakage**:
   - The validation set (`val.csv`) is reserved strictly for temperature scaling ($T^*$) and threshold calibration ($\tau^*$).
   - Decision-level meta-classifiers must be trained strictly on Out-of-Fold (OOF) cross-validation logits from the training set.
   - The test set (`test.csv`) must remain completely untouched until final benchmark evaluation.

2. **Data Isolation**:
   - `data/fakeddit/`: Benchmark data only. Missing or corrupt Reddit images must be replaced exclusively by querying other valid paired samples from the Fakeddit corpus. Never introduce synthetic or external images into this folder.
   - `data/demo_curated/`: Isolated development and live demonstration dataset (20–50 samples). Must only use verified Public Domain (CC0) or Creative Commons (CC-BY, CC-BY-SA) images with recorded URLs and license attributions.

3. **Attribution Integrity**:
   - Never label heuristic or gradient attribution as SHAP. Only results from `shap.Explainer` with the partition algorithm are labeled as SHAP.
   - Grad-CAM must always be accompanied by a scientific disclaimer clarifying that it highlights model-influential regions, not pixel-level forensic manipulation.
   - Never use embedding vector L2-norms as a proxy for modality importance; use marginal prediction drop ($\Delta P$) from modality ablation.

4. **Zero Fabrication**:
   - Never fabricate or hardcode benchmark metrics or confidence scores. All metrics in the UI/reports must be generated by actual test runs.

### Methodological & Experimental Findings (Audit Day 2.1)

1. **Explanation of Macro F1 Discrepancy**:
   - In the initial Day 2 evaluation, `f1_score()` from scikit-learn was invoked with default parameters (`average='binary'`, `pos_label=1`). Consequently, the reported 82.90% (DistilBERT) and 80.55% (ResNet50) corresponded strictly to the positive (FAKE) class F1 score rather than the unweighted macro average.
   - The true unweighted Macro F1 scores are **66.52%** for DistilBERT and **57.48%** for ResNet50. Model checkpoints, weights, and raw predictions remain completely unaltered and authentic.

2. **Threshold Search Methodology & Terminology**:
   - In the validation sweep, decision thresholds were evaluated across the discrete 9-point grid:
     $$\mathcal{T} = \{0.30, 0.40, 0.50, 0.55, 0.60, 0.65, 0.70, 0.75, 0.80\}$$
     *(Note: grid spacing is non-uniform, with $\Delta \tau = 0.10$ in $[0.30, 0.50]$ and $\Delta \tau = 0.05$ in $[0.50, 0.80]$).*
   - The values $\tau = 0.65$ (DistilBERT) and $\tau = 0.55$ (ResNet50) represent the **best-performing thresholds among the sampled candidate values in this discrete validation grid**, using validation Macro $F_1$ as the selection criterion.
   - They must not be described as globally optimal; a continuous search or finer grid sweep could yield a different numerical threshold.

3. **Decoupling Temperature Scaling, Binary Thresholding, and Selective Abstention**:
   - These three distinct mathematical operations must remain strictly separated:
     - **Temperature Scaling ($T^*$)**: Adjusts predicted probability magnitudes to improve calibration. The temperature parameter is optimized by minimizing validation Negative Log-Likelihood (NLL). Because scalar division by $T^* > 0$ is strictly monotonic, it preserves logit rank ordering and preserves argmax predictions under standard argmax decision rules. Its effect on calibration is subsequently evaluated using metrics such as Expected Calibration Error (ECE) and Brier score. Improvement in these metrics is not guaranteed. *Temperature scaling alone does not guarantee improved classification accuracy or REAL recall.*
     - **Binary Decision Threshold Selection ($\tau_{\text{binary}}$)**: Selects an operating cutoff along the ROC curve ($\hat{y} = 1 \iff \hat{p}_1 \ge \tau_{\text{binary}}$) to balance precision and recall.
     - **Selective Classification ($\tau^*$)**: An abstention mechanism where predictions with maximum confidence below $\tau^*$ are returned as `UNCERTAIN` ($\max(\hat{p}_0, \hat{p}_1) < \tau^*$), trading coverage for selective accuracy.
   - *Operational Interaction*: Applying binary thresholding ($\tau_{\text{binary}}$) and selective abstention ($\tau^*$) to *calibrated* probabilities ensures that thresholding decisions reflect empirically trustworthy confidence levels rather than uncalibrated overconfidence.

4. **Multi-Factor Explanation of Prediction Skew**:
   - The $2.08:1$ class prior (32.4% REAL, 67.6% FAKE) is a plausible contributor, but it is **not** the sole cause of the prediction bias toward FAKE.
   - Analysis of validation probability distributions reveals **substantial representation overlap** in unimodal feature spaces:
     - DistilBERT validation: REAL claims exhibit mean $P(\text{FAKE}) = 0.5246$ ($\text{median} = 0.5004, \sigma = 0.1917$).
     - ResNet50 validation: REAL claims exhibit mean $P(\text{FAKE}) = 0.5496$ ($\text{median} = 0.5297, \sigma = 0.1562$).
   - Because significant probability mass for genuine REAL claims falls at and above $0.50$, the high false-positive rate at $\tau = 0.50$ ($60.49\%$ for DistilBERT, $75.72\%$ for ResNet50) is the compound outcome of:
     1. **Unimodal Feature Ambiguity**: Linguistic sensationalism in real Reddit headlines and meme-like aesthetics in real images create intrinsic overlap between classes.
     2. **Prior Class Imbalance**: Training with unweighted cross-entropy slightly tilts gradient descent toward the majority class.
     3. **Fixed Threshold Placement**: A default cutoff of $\tau = 0.50$ bisects the overlapping probability distribution of REAL claims, forcing ambiguous samples into FAKE classifications.

5. **Authoritative Dataset Labeling Schema**:
   - The original Fakeddit taxonomy (Nakamura et al., 2020) defines the 6-way categories as:
     - **0**: True News
     - **1**: Satire / Parody
     - **2**: Misleading Content
     - **3**: Imposter Content
     - **4**: False Connection
     - **5**: Manipulated Content
   - In Veritas AI, collapsing classes 1–5 into `FAKE` is an **operational project definition** for automated content verification benchmarking, not a universal ontological definition of falsehood. Satire, parody, and humor operate rhetorically rather than fraudulently.

*Key finding:* Text modality demonstrates significantly higher discriminative power than the visual modality on Fakeddit (ROC-AUC 81.10% vs 73.76%), motivating the multimodal fusion strategies implemented in Day 3.
